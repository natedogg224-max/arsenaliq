Evaluation model
Pitch grades are normalized within pitch type using whiff%, RV/100, xwOBA, hard-hit% and velocity. Arsenal grade is usage-weighted. This avoids comparing a curveball's raw velocity directly to a four-seamer.

Official data sources

Pitch Arsenal Stats → pitch-level outcomes. Pitch Arsenals → average velocity. Pitch Movement → movement relative to league. Minimum workload can be controlled when you download each leaderboard.

Methodology

Transparent, process-first pitcher evaluation.

ArsenalIQ Model

Pitch Quality

Each pitch is compared only with the same pitch type. Current inputs: whiff%, run value per 100 pitches, xwOBA allowed and hard-hit rate. Percentile performance is converted to the 20–80 scouting scale.

Arsenal Grade

Pitch grades are weighted by usage. This rewards pitchers with multiple real weapons without allowing a rarely used pitch to dominate the overall grade.

Arsenal Interaction

Movement, velocity and release traits are stored so separation and compatibility models can be layered in without changing the player database.

Projection

Projection currently blends Arsenal grade with expected-performance signal. It is an ArsenalIQ model output—not a claim of future certainty.

Command

Command is intentionally not fabricated from strike rate. The field remains blank for bundled leaderboard data until pitch-level location/context modeling is available.

Evaluation Gap

Highlights disagreement between process and performance to prioritize deeper review; it is a scouting flag, not a buy/sell verdict.
